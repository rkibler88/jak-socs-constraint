# JAK–SOCS evolutionary constraint and specificity

Analysis of purifying selection and paralogue specificity across the JAK kinase
family (JAK1, JAK2, TYK2) and the SOCS family (SOCS1, SOCS3, with SOCS2 as a
non-binding contrast), tested against the two available JAK–SOCS co-crystal
interfaces. JAK3 is excluded throughout, enforced by sequence rather than by
query construction.

The project began as an inter-protein direct-coupling analysis. That is not
attainable at the available sequence depth, and quantifying why is part of the
result; see §"Depth" below.

`results/tables/MANIFEST.csv` lists every published file with its byte size, a
truncated SHA-256, the internal name it was produced under, and a one-line
description. It is generated by stage 12, so it cannot drift from the contents.

## Usage

```bash
conda env create -f environment.yml && conda activate jak-socs-constraint

./run_pipeline.sh                 # full run
./run_pipeline.sh --quick         # reduced permutation counts, ~5 min
./run_pipeline.sh --only 08       # re-run one stage against the shipped outputs
./run_pipeline.sh --from 05       # resume from stage 05
```

Stages read and write a flat working directory (`work/analysis/`) using short
internal names; stage 12 maps those onto the published tree. Running any stage
with `--only` or `--from` first seeds the working directory from the shipped
tree, so no stage requires re-running the 45-minute retrieval.

Stages 01–02 query UniProt (~50 min total, 14,338 sequence fetches) and stage 07
downloads two mmCIF files from RCSB; every other stage is offline. Seed is fixed
at 42 in all scripts, so permutation and bootstrap results are reproducible.

## Data provenance

Sequences: UniProtKB, accessed 29 September 2026, retrieved by InterPro
signature — `IPR016251` for the JAK family, `IPR000980` ∧ `IPR001496` for the
SOCS family — across Metazoa (taxid 33208), then assigned to paralogues by
MMseqs2 search against a twelve-protein human reference panel that includes
JAK3, SOCS2, SOCS4–7 and CIS as decoys. 14,338 entries retrieved, 5,899
accepted, yielding 617 JAK1, 648 JAK2, 366 TYK2, 704 SOCS1, 704 SOCS3 and 598
SOCS2 species. Exact query strings are in `results/logs/uniprot_queries.json`.

Structures: PDB **4GL9** (Kershaw et al. 2013, `10.1038/nsmb.2519`) and **6C7Y**
(Liau et al. 2018, `10.1038/s41467-018-04013-1`). Note that neither uses the
human protein throughout — 4GL9 is mouse JAK2 + mouse SOCS3, 6C7Y is human JAK1
+ chicken SOCS1 — so all structure-to-alignment mapping runs through each
structure's own organism.

Domain boundaries are UniProt feature annotations, not hardcoded: JAK1 JH1
875–1153, JAK2 JH1 849–1124, TYK2 JH1 897–1176; SOCS1 KIR 55–66, ESS 67–78,
SH2 79–174, SOCS box 161–210; SOCS3 KIR 22–33, ESS 34–45, SH2 46–142, SOCS box
177–224; SOCS2 SH2 48–156, SOCS box 151–197, with no KIR or ESS annotated.

## Depth

Inter-protein coupling inference requires N_eff > (L₁+L₂)/2 (Ovchinnikov,
Kamisetty & Baker, eLife 2014). Twelve candidate designs were evaluated; all
fail, at ratios 0.037–0.586. The cause is conservation, not sampling effort:
median pairwise identity in a JAK2 × SOCS3 alignment of 365 species is 0.904 and
73.5% of sequence pairs exceed the 80% redundancy threshold, so those species
collapse to N_eff = 8.1. Taxonomic breadth is capped by annotation — extending
to Metazoa adds 81 paired species because invertebrate JAKs are largely
unannotated — though those 81 arthropod species are individually ~14× more
informative per record than the 2,045 vertebrate ones. See
`docs/depth_scoping_report.md` and `results/tables/01_depth_scoping_designs.csv`.

## Notes for reuse

- **`lib_constraint.henikoff_weights` is not interchangeable with
  `lib_sequence.sequence_weights`.** The former is position-based weighting for
  conservation scoring; the latter is 80%-identity redundancy weighting for
  depth diagnostics. Using the latter for conservation discards nearly all the
  data (JAK2: N_eff 8.8 from 625 sequences).
- **Every constraint and specificity result is reported with and without gap
  content separated.** Jensen-Shannon divergence is gap-penalised, so a module
  that is deleted in one paralogue scores low for two distinct reasons; the
  decomposition tables exist to keep them apart.
- **Specificity p-values are not a selection criterion here.** At n = 2,006 the
  permutation test flags 132 of 235 columns even at the family-wise maximum.
  Rank by effect size.
- **The average product correction forces the inter-block mean to ≈0.** The mean
  coupling statistic is reported in
  `10_coupling_vs_scrambled_null.csv` but flagged non-interpretable; inference
  rests on the tail statistics.
